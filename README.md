# Impact Candle

แอปวิเคราะห์ผลกระทบของข่าวและเหตุการณ์ต่อการลงทุน  
แสดงผลในรูปแบบแท่งเทียน (Impact Candles) สำหรับ:

- Gold
- DXY
- US100
- US30
- SP500

## คุณสมบัติหลัก

- Daily Impact Candles
- Fear & Greed Index
- Trade Suggestion
- Best Opportunity Today
- Weekly Recommendation
- Historical View
- Event Shock Simulator (AI)

## โครงสร้าง

- backend/ = ส่วน AI
- app/ = แอปมือถือ Flutter

## วิธีใช้

ดูรายละเอียดเพิ่มเติมทีหลัง
